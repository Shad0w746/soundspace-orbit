# Changelog

All notable changes to SoundSpace Orbit will be tracked here.

## 0.1.0 - 2026-08-31

- Added the first working conversion core.
- Added a Tkinter desktop interface.
- Added a command-line interface with visible version output.
- Added FFmpeg discovery through PATH, `SOUNDSPACE_FFMPEG`, or `imageio-ffmpeg`.
- Added URL input support through `yt-dlp` when installed.
